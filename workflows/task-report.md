# Task Report

Conclude each completed task with:

## Changed

What changed and the resulting user-facing or engineering outcome.

## Inspected

Files, systems, assets, runtime paths, or external records inspected.

## Related Systems

Callers, callees, shared types, validation, configuration, tests, deployment paths, or documentation checked.

## Extra Issues Fixed

Related issues fixed because they shared the root cause, could break the requested behavior, or were necessary for consistency.

## Out of Scope

Issues noticed but intentionally left out of the task.

## Verification

Checks run and the evidence they produced.

## Assumptions and Risks

Assumptions made, unavailable checks, remaining uncertainty, and known risks.
