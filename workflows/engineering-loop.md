# Engineering Loop

For every project task:

1. Inspect before editing.
2. Identify the likely blast radius.
3. Check directly related systems, not only the literal file named in the request.
4. Keep the work within the approved scope.
5. Verify the real output using the most relevant available checks.
6. Report what changed, what was inspected, and what verification established.
