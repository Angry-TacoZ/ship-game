# Pull Request Change

Before modifying an existing pull request:

1. Read the pull-request description.
2. Review its commits.
3. Read the review threads.
4. Check the latest CI results.
5. Use that information to determine the approved scope and required verification.
6. Record task-specific plans, decisions, progress, and handoff notes in the relevant GitHub issue or pull request.
